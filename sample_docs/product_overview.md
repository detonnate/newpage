# Newpage Product Overview

## Product vision
Newpage builds AI-powered knowledge systems that help teams ask questions about internal documentation and external content. We focus on software that reduces the time spent searching for answers and improves policy compliance.

## Key features
- Smart document ingestion for PDFs, markdown, text files, and structured notes
- Retrieval-augmented generation to answer user questions from trusted sources
- Source snippets that show where the answer came from
- Human review workflow for sensitive decisions and policy checks

## Roadmap
Q1: launch internal document assistant for engineering and support teams
Q2: improve ranking quality using metadata and user feedback
Q3: enable enterprise trust features including admin controls, audit logs, and approval workflows

## Pricing
Starter: $29/user/month
Growth: $79/user/month
Enterprise: custom

## Security commitments
We use encryption in transit and at rest, enforce least-privilege access, and require approval for any public model integrations that touch customer data.
